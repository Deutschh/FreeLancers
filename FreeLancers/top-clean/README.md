# Top Clean — landing page comercial

Protótipo visual independente em React, Vite e Tailwind CSS para a Top Clean. O conteúdo é estático, sem backend, formulário, persistência ou coleta de dados.

## Executar localmente

```bash
cd top-clean
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run lint
npm run build
npm run preview
```

## Imagens ilustrativas geradas

Todas as fotografias abaixo foram criadas com a geração integrada de imagens e são tratadas no site como conteúdo ilustrativo, sem atribuição a clientes ou trabalhos reais da Top Clean:

- `compare-sofa-before.jpg` e `compare-sofa-after.jpg` — sofá alinhado antes/depois; também sustenta o recorte visual do hero.
- `compare-armchair-before.jpg` e `compare-armchair-after.jpg` — poltrona alinhada antes/depois.
- `compare-auto-before.jpg` e `compare-auto-after.jpg` — banco automotivo alinhado antes/depois.
- `residential-room.jpg` — ambiente residencial claro com sofá e poltrona.
- `auto-cleaning-process.jpg` — processo de extração em banco automotivo, sem pessoa identificável.
- `waterproofing-detail.jpg` — aplicação ilustrativa de impermeabilização em tecido.

Os prompts pediram fotografia comercial realista, paleta azul-marinho/ciano, ausência de textos, logos e marcas, diferenças moderadas nos comparativos e nenhuma promessa de resultado extremo. Os dípticos foram separados ao centro e os ativos finais foram comprimidos em JPEG; a logo permanece em PNG.

Não foram usadas imagens externas neste projeto.
