# Limpklin — landing page comercial

Protótipo visual independente para a Limpklin, desenvolvido com React, Vite, Tailwind CSS, Lucide React e Framer Motion. O projeto não possui backend nem coleta de dados.

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

## Imagens do site

As fotografias foram criadas com a geração integrada de imagens para este protótipo e depois otimizadas localmente em JPEG. Elas são ilustrativas: não representam funcionários, clientes, atendimentos ou resultados reais da Limpklin. Não foram utilizadas fotografias externas de bancos de imagem.

- `hero-profissional.jpg` — profissional não identificável higienizando sofá; fotografia documental vertical.
- `processo-poltrona.jpg` — detalhe de mãos, extratora e poltrona.
- `processo-colchao.jpg` — higienização ilustrativa de colchão.
- `impermeabilizacao.jpg` — demonstração ilustrativa de aplicação e gotas sobre tecido.
- `comparativo-sofa-antes.jpg` e `comparativo-sofa-depois.jpg` — par ilustrativo alinhado para o comparador.
- `comparativo-colchao-antes.jpg` e `comparativo-colchao-depois.jpg` — par ilustrativo alinhado para o comparador.

### Diretrizes usadas nos prompts

- Fotografia natural e documental, com luz quente e ambiente residencial realista.
- Uniforme marinho e azul-claro sem logo ou marca.
- Pessoas não identificáveis e sem reprodução do rosto presente nas referências.
- Sem textos, marcas, logos ou marcas d'água nas imagens.
- Comparativos com a mesma câmera, geometria, iluminação e composição; alteração restrita à aparência do tecido.
